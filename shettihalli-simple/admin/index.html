📊 How to connect Google Sheets

  1. Create a Google Sheet with columns:
    id, name, category, price, originalPrice, unit, shortDesc, image, badge, inStock, status, stockQty, rating, reviews, origin, weight, harvest, discount
  2. File → Share → Publish to web → CSV → copy the URL
  3. Open app.js → paste URL into SHEET_CSV_URL
  4. Website now loads products live from the Sheet!
